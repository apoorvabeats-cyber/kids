# FunLearn

Kids learning simulator as a **single HTML file**. No install. Open `index.html` in a browser.

## Play it

- **This file:** [index.html](index.html) — download and double-click it
- **GitHub HTML preview:** [open FunLearn](https://htmlpreview.github.io/?https://github.com/apoorvabeats-cyber/kids/blob/main/index.html)

To host it on GitHub Pages: Settings → Pages → Deploy from **main** / **root**.

## What is inside

- English alphabets A–Z
- Hindi varnmala (swar and vyanjan)
- Numbers 1–100
- Animals, birds, and everyday sounds
- Nursery rhymes and short English sentences
- Days of the week and months of the year
- Rashtra Gaan and Rashtra Geet
- Freedom fighters
- Big flashcards with Play, Previous, and Next
- A find-the-card quiz
- Stars for cards you already opened (saved in this browser)

## How to use

1. Pick a topic.
2. Tap a card. A big flashcard opens.
3. Tap **Play** for sound (allow audio if the browser asks).
4. Use **Next** / **Previous**, then try **Quiz**.

Hindi speech needs a Hindi voice on the device.

## Privacy

Nothing is uploaded. Progress stays on the device.
